# คู่มือการใช้งาน Intersite Track

คู่มือนี้อธิบายการใช้งานเว็บ Intersite Track สำหรับแอดมินและพนักงาน ตั้งแต่เข้าสู่ระบบ จัดการงาน ติดตามทีม รายงาน ไปจนถึงการตั้งค่าพื้นฐาน

## 1. การเริ่มใช้งาน

### เปิดระบบ

- ระหว่างพัฒนา: `http://localhost:5173`
- Backend API: `http://localhost:3694`
- Health check: `http://localhost:3694/api/health`

### เข้าสู่ระบบ

1. เปิดหน้าเว็บ
2. กรอกอีเมลและรหัสผ่าน
3. กด **เข้าสู่ระบบ**
4. ถ้าเข้าสู่ระบบสำเร็จ ระบบจะพาไปหน้าแดชบอร์ด

### สมัครบัญชีใหม่

1. ที่หน้าเข้าสู่ระบบ กด **สร้างบัญชีใหม่**
2. กรอกอีเมล
3. ตั้งรหัสผ่านตามเงื่อนไขที่ระบบแจ้ง
4. กรอกรหัสผ่านซ้ำ
5. กด **สร้างบัญชี**

บัญชีที่สมัครผ่านหน้าเว็บจะเป็น role `staff` โดยค่าเริ่มต้น ถ้าต้องการสิทธิ์แอดมินให้ผู้ดูแลระบบแก้ role ในหน้าจัดการพนักงานหรือในฐานข้อมูล

### ลืมรหัสผ่าน

1. กด **ลืมรหัสผ่าน?**
2. กรอกอีเมล
3. กดส่งลิงก์รีเซ็ต
4. เปิดอีเมลและตั้งรหัสผ่านใหม่

## 2. สิทธิ์ผู้ใช้งาน

### แอดมิน

แอดมินสามารถใช้งานทุกเมนูหลักได้ รวมถึง:

- ดูภาพรวมทั้งองค์กร
- สร้าง แก้ไข ลบงาน
- จัดการโปรเจกต์
- จัดการพนักงาน
- ดูรายงาน
- ตั้งค่าข้อมูลพื้นฐาน
- จัดการวันหยุดและเวรเสาร์

### พนักงาน

พนักงานใช้งานระบบเพื่อทำงานของตัวเองและดูข้อมูลที่เกี่ยวข้องได้ เช่น:

- ดูแดชบอร์ดของตัวเอง
- ดูงานที่ได้รับมอบหมาย
- อัปเดตสถานะงาน
- ดูการแจ้งเตือน
- เชื่อม LINE
- ดูวันหยุดและเวรเสาร์
- ดู KPI/OKR ที่เกี่ยวข้อง

## 3. เมนูแดชบอร์ด

หน้าแดชบอร์ดใช้ดูภาพรวมงานอย่างรวดเร็ว

สิ่งที่ทำได้:

- ดูจำนวนงานตามสถานะ
- ดูงานใกล้ครบกำหนด
- ดูงานล่าสุด
- กดเข้าไปดูรายละเอียดงาน
- ไปยังหน้าจัดการงานทั้งหมด

## 4. เมนูจัดการโปรเจกต์

ใช้สร้างและติดตามโปรเจกต์ขององค์กร

ขั้นตอนทั่วไป:

1. เข้าเมนู **จัดการโปรเจกต์**
2. ดูรายการโปรเจกต์ทั้งหมด
3. กดสร้างโปรเจกต์ใหม่ หรือเลือกโปรเจกต์เดิมเพื่อดูรายละเอียด
4. แก้ไขข้อมูลตามสิทธิ์ของผู้ใช้

## 5. เมนูภาระงานทีม

ใช้ดูภาระงานของทีมและช่วยตัดสินใจเรื่องการกระจายงาน

สิ่งที่ควรตรวจ:

- ใครมีงานมากเกินไป
- งานไหนค้างหรือใกล้ deadline
- ทีมไหนมีภาระงานสูง
- งานที่ควรย้ายหรือแบ่งให้คนอื่น

## 6. เมนูจัดการงาน

เมนูนี้เป็นศูนย์กลางของระบบ

### สร้างงาน

1. กดปุ่มสร้างงาน
2. กรอกชื่องาน
3. ใส่รายละเอียด
4. เลือกประเภทงานและความสำคัญ
5. กำหนดวันครบกำหนด
6. เลือกผู้รับผิดชอบ
7. กดบันทึก

### ค้นหาและกรองงาน

ใช้ตัวกรองเพื่อหาเฉพาะงานที่ต้องการ:

- คำค้น
- สถานะ
- ความสำคัญ
- ผู้รับผิดชอบ
- ช่วงวันที่
- โปรเจกต์

### ดูรายละเอียดงาน

กดที่งานเพื่อเปิดรายละเอียด สามารถดู:

- รายละเอียดงาน
- ผู้รับผิดชอบ
- สถานะ
- Checklist
- ความคืบหน้า
- ไฟล์แนบ
- ประวัติการอัปเดต

### อัปเดตงาน

ผู้ใช้ที่มีสิทธิ์สามารถ:

- แก้ไขหัวข้อและรายละเอียด
- เปลี่ยนสถานะ
- เพิ่ม checklist
- อัปโหลดไฟล์แนบ
- เพิ่มหรือแก้ผู้รับผิดชอบ

## 7. เมนูพนักงาน

เมนูนี้เห็นเฉพาะแอดมิน

สิ่งที่ทำได้:

- ดูรายชื่อพนักงาน
- เพิ่มพนักงาน
- แก้ไขชื่อ ตำแหน่ง แผนก และ role
- ลบพนักงาน
- รีเซ็ตรหัสผ่านให้พนักงาน

คำแนะนำ:

- ใช้ role `admin` เฉพาะคนที่ต้องจัดการระบบจริง
- ใช้ role `staff` สำหรับผู้ใช้งานทั่วไป
- ตรวจสอบอีเมลให้ถูกต้องก่อนสร้างบัญชี เพราะระบบต้องผูกกับ Firebase Auth

## 8. เมนูรายงาน

เมนูนี้เห็นเฉพาะแอดมิน

ใช้สำหรับดูภาพรวมผลการทำงาน เช่น:

- งานตามสถานะ
- งานตามพนักงาน
- งานล่าช้า
- KPI และประสิทธิภาพทีม
- Export รายงานเป็น PDF

## 9. เมนูการแจ้งเตือน

ใช้ดูการแจ้งเตือนในระบบ

สิ่งที่ทำได้:

- ดูรายการแจ้งเตือน
- กดอ่านรายละเอียด
- กดไปยังงานที่เกี่ยวข้อง
- Mark as read
- Mark all as read

ระบบสามารถแจ้งเตือนได้จาก:

- งานใหม่
- งานถูกแก้ไข
- งานเปลี่ยนสถานะ
- Deadline ใกล้ถึง
- วันหยุด
- เวรเสาร์

## 10. เมนู KPI & OKR

ใช้ติดตามเป้าหมายและความคืบหน้า

สิ่งที่ทำได้:

- ดูเป้าหมาย
- ดูเปอร์เซ็นต์ความคืบหน้า
- อัปเดต check-in
- ติดตาม OKR ของทีม

## 11. เมนูรออนุมัติ

ใช้ดูงานหรือรายการที่ต้องผ่านการอนุมัติ

ขั้นตอนใช้งาน:

1. เข้าเมนู **รออนุมัติ**
2. เลือกรายการที่ต้องตรวจ
3. อ่านรายละเอียด
4. อนุมัติหรือปฏิเสธตามสิทธิ์

## 12. เมนูเชื่อม LINE

ใช้ผูกผู้ใช้กับ LINE เพื่อรับแจ้งเตือน

ขั้นตอนทั่วไป:

1. เข้าเมนู **เชื่อม LINE**
2. ทำตามคำแนะนำบนหน้าเว็บ
3. ใส่หรือยืนยัน LINE User ID ตาม flow ที่ตั้งไว้
4. บันทึก

สำหรับแจ้งเตือน group ให้เพิ่ม LINE bot เข้า group ระบบจะบันทึก `group_id` ผ่าน webhook เมื่อได้รับ event จาก LINE

## 13. เมนูวันหยุด

ใช้ดูและจัดการวันหยุดประจำปี

แอดมินสามารถ:

- เพิ่มวันหยุด
- แก้ไขวันหยุด
- ลบวันหยุด

พนักงานสามารถ:

- ดูวันหยุด
- ตรวจสอบว่าวันไหนเป็นวันทำงานหรือวันหยุด

## 14. เมนูเวรเสาร์

ใช้จัดการตารางเวรวันเสาร์

แอดมินสามารถ:

- เพิ่มรอบเวร
- แก้ไขผู้เข้าเวร
- Import ตารางเวร
- ลบรายการเวร

พนักงานสามารถ:

- ดูเวรที่เกี่ยวข้อง
- ลงทะเบียนเวรตัวเองถ้าเปิดให้ทำได้

## 15. เมนูข้อมูลพื้นฐาน

เมนูนี้เห็นเฉพาะแอดมิน

ใช้ตั้งค่าข้อมูลที่ระบบต้องใช้ร่วมกัน เช่น:

- ประเภทงาน
- Template งาน
- การเชื่อม Trello
- Log การ sync
- ข้อมูลพื้นฐานอื่นของระบบ

## 16. โปรไฟล์ผู้ใช้

กดชื่อผู้ใช้ที่ sidebar เพื่อเปิดโปรไฟล์

สิ่งที่แก้ไขได้:

- ชื่อผู้ใช้
- ชื่อและนามสกุล
- ตำแหน่ง
- LINE User ID
- รหัสผ่าน

## 17. วิธีตรวจว่าระบบพร้อมใช้งาน

ใช้คำสั่งต่อไปนี้จาก root ของโปรเจกต์ `TaskAm-main`:

```bash
npm run lint
npm run test
npm run build
npm run test:e2e
```

เกณฑ์ผ่านขั้นต่ำ:

- TypeScript ไม่มี error
- Unit/backend tests ผ่าน
- Frontend build สำเร็จ
- E2E mock flow ผ่าน
- ไม่มี generated reports หรือ logs ถูก track ใน git

## 18. ปัญหาที่พบบ่อย

### เข้าสู่ระบบไม่ได้

- ตรวจว่า Firebase Auth มี user นี้จริง
- ตรวจว่ามี Firestore profile ใน collection `users`
- ตรวจ `.env` ว่า Firebase config ถูกต้อง

### หน้าเว็บเรียก API ไม่ได้

- ตรวจว่า backend รันที่ port `3694`
- ตรวจว่า frontend รันที่ port `5173`
- ตรวจ `ALLOWED_ORIGIN`

### ไม่ได้รับ LINE notification

- ตรวจ `LINE_CHANNEL_ACCESS_TOKEN`
- ตรวจ `LINE_CHANNEL_SECRET`
- ตรวจว่า bot ถูกเพิ่มเข้า group แล้ว
- ตรวจ webhook `/api/line/webhook`

### Upload ไฟล์ไม่ได้

- ตรวจขนาดไฟล์ไม่เกิน limit
- ตรวจว่า login แล้ว
- ตรวจค่า `BLOB_READ_WRITE_TOKEN` ใน production

### Staff เห็นข้อมูลไม่ครบ

เป็นพฤติกรรมปกติของระบบ สิทธิ์ staff จะถูกจำกัดให้เห็นเฉพาะข้อมูลที่เกี่ยวข้องกับงานและสิทธิ์ของตัวเอง
